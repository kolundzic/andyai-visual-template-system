# AndyAI Visual Style Guide v0.1

## Visual Direction

**Japanese Future Academic**

A calm, precise, elegant, futuristic visual language for academic diagrams, product mockups, repo documentation, educational assets, and business presentations.

## Design Identity

The visual identity should feel like:

- future research lab
- Japanese editorial design
- premium software documentation
- enterprise-grade AI system
- calm sci-fi interface
- academic learning environment
- high-trust technical product

## Color System

### Primary Base Colors

| Name | Hex | Meaning |
|---|---:|---|
| Midnight Navy | `#07111F` | primary dark background |
| Deep Graphite | `#111827` | secondary panels |
| Ink Black | `#05070B` | strong contrast |
| Pearl White | `#F7F8FA` | primary readable text |
| Silver Mist | `#B8C2CC` | secondary text / neutral UI |

### Semantic Accent Colors

| Name | Hex | Meaning |
|---|---:|---|
| Jade Green | `#19B37A` | verified / approved / healthy |
| Soft Cyan | `#4DD7FF` | data / structure / precision |
| Electric Violet | `#8B5CF6` | AI / intelligence / model layer |
| Warm Gold | `#D4AF37` | authority / priority / premium insight |
| Sakura Rose | `#F6A6C8` | human layer / empathy / attention |
| Controlled Red | `#EF4444` | risk / blocked / failed |

## Rules

1. Color must carry meaning.
2. Glow must be subtle and controlled.
3. Empty space is part of the design.
4. Labels must be short and functional.
5. No chaotic cyberpunk.
6. No generic stock visuals.
7. No fake logos.
8. No unreadable tiny text.
9. No decorative arrows without logic.
10. Every visual must teach, prove, explain, or guide.

## Typography

Use clean sans-serif typography.  
Titles are strong. Labels are short. Body text is minimal.

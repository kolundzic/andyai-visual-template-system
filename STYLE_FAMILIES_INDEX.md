# AndyAI Style Families Index v0.2

This index defines reusable visual style families for the AndyAI Visual Template System.

## Style Family Call Syntax

```text
Style Family: [family-name]
Mood: [calm / operational / academic / premium / human / executive]
Palette: [semantic color set]
Output: [diagram / poster / dashboard / card / character sheet]
```

---

## 1. Japanese Future Academic

**Use for:** core academic diagrams, system maps, canonical explainers.  
**Mood:** calm, precise, futuristic, refined.  
**Palette:** Midnight Navy, Pearl White, Soft Cyan, Jade Green, Warm Gold.  
**Visual traits:** soft glow, elegant grid, generous whitespace, thin dividers, precise labels.

## 2. Pearl White Research

**Use for:** research cards, white papers, public documentation, clean comparison visuals.  
**Mood:** bright, trustworthy, editorial, academic.  
**Palette:** Pearl White, Ink Black, Silver Mist, Jade Green, Warm Gold.  
**Visual traits:** bright background, subtle borders, restrained icons, high legibility.

## 3. Dark Navy Operational

**Use for:** dashboards, mission control, status boards, system operations.  
**Mood:** enterprise, live, controlled, technical.  
**Palette:** Midnight Navy, Deep Graphite, Soft Cyan, Electric Violet, Jade Green.  
**Visual traits:** dark panels, live status chips, data cards, thin neon separators.

## 4. Graphite Evidence Lab

**Use for:** proof cards, audits, verification reports, trust score panels.  
**Mood:** serious, forensic, factual, verifiable.  
**Palette:** Deep Graphite, Pearl White, Jade Green, Controlled Red, Warm Gold.  
**Visual traits:** status-first layout, evidence rows, audit icons, timestamp zones.

## 5. Sakura Human Layer

**Use for:** human approval, learning, attention, ethics, care, judgment.  
**Mood:** warm, humane, calm, supportive.  
**Palette:** Pearl White, Sakura Rose, Jade Green, Silver Mist, Soft Cyan.  
**Visual traits:** soft rounded cards, human-centered icons, gentle hierarchy.

## 6. Gold Authority Layer

**Use for:** executive summary, strategy, premium insight, decision boards.  
**Mood:** authoritative, elegant, high-value, strategic.  
**Palette:** Ink Black, Warm Gold, Pearl White, Deep Graphite.  
**Visual traits:** strong title hierarchy, gold highlights, concise premium panels.

## 7. Cyber Zen Blueprint

**Use for:** technical architecture, protocols, repo pipelines, engineering maps.  
**Mood:** precise, engineered, futuristic but controlled.  
**Palette:** Ink Black, Blueprint Cyan, Jade Green, Silver Mist.  
**Visual traits:** blueprint grid, fine linework, technical nodes, architectural spacing.

## 8. Quantum Glass Interface

**Use for:** product concept UI, SaaS mockups, future dashboards.  
**Mood:** glassy, premium, advanced, calm.  
**Palette:** Midnight Navy, Transparent Graphite, Violet, Cyan, Pearl White.  
**Visual traits:** frosted glass cards, subtle gradients, soft depth, clean UI sections.

## 9. Minimal Scholar Light

**Use for:** beginner education, academy lessons, print-friendly visuals.  
**Mood:** simple, readable, academic, friendly.  
**Palette:** Pearl White, Ink Black, Jade Green, Soft Gold.  
**Visual traits:** high contrast, short labels, minimal icons, clean margins.

## 10. Neon Ink Diagram

**Use for:** high-impact social explainers, launch visuals, canonical posters.  
**Mood:** dramatic, modern, sharp, memorable.  
**Palette:** Ink Black, Violet, Cyan, Warm Gold, Pearl White.  
**Visual traits:** dark background, controlled glow, bold typography, strong section rhythm.

# AVTS-007 — Agent Guide Character Sheet

## Category
Character / Guide System

## Purpose
Create stable, reusable visual guide characters or agent personas for AndyAI educational and product systems.

## Best For
- AI guide characters
- agent role visualization
- educational personas
- onboarding helpers
- system role explainers

## Style Family
Sakura Human Layer

## Recommended Ratio
1:1

## Prompt

```text
Create a consistent character guide sheet for [character / agent name].

Role:
[role in the AndyAI system]

Personality:
calm, intelligent, supportive, precise, trustworthy.

Fixed features:
[hair / face / outfit / accessory / signature object / color palette]

System meaning:
This character represents [orchestration / verification / memory / human approval / learning / evidence].

Show:
- large hero pose
- front view
- 3/4 view
- side view
- back view
- 4 expressions
- 3 action poses
- accessory panel
- color palette
- detail closeups

Style:
refined Japanese-inspired character design, elegant academic sci-fi, approachable but professional, stable identity.

Main color palette:
[project-specific palette]

Text labels:
Render labels clearly and accurately.

Avoid:
style drift, childish randomness, inconsistent face, random outfit changes, copying existing characters, watermark.
```

## Project Mapping
- AndyAI Director
- AndyAI Academy
- Human Attention
- Agency OS
- Visual Canon

## Quality Gate
The character must be reusable across a series without identity drift.

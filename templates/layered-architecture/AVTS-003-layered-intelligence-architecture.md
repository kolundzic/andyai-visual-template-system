# AVTS-003 — Layered Intelligence Architecture

## Category
Layered Architecture Map

## Purpose
Explain a multi-layer AndyAI system as a stack of human, orchestration, execution, verification, memory, and reporting layers.

## Best For
- Director architecture
- PAIA-OS
- Knowledge Factory
- Memory Runtime Lab
- AI governance stack
- OS-like systems

## Style Family
Japanese Future Academic

## Recommended Ratio
16:9

## Prompt

```text
Generate a layered intelligence architecture diagram for [system name].

Purpose:
Show the full stack of the system from human intent to memory and reporting.

Audience:
technical, strategic, educational.

Layers to include:
1. Human Intent Layer
2. Interface / Request Layer
3. Orchestration Layer
4. Worker / Action Layer
5. Verification / Evidence Layer
6. Memory / Knowledge Layer
7. Reporting / Dashboard Layer

For each layer include:
- layer title
- one short role description
- 2–4 subcomponents

Core logic:
The human defines intent. The system routes and executes. Verification creates proof. Memory preserves reusable knowledge. Dashboard explains the state.

Style:
AndyAI academic sci-fi, Japanese Future Academic, calm futuristic, elegant, precise.

Layout:
Stacked horizontal layers, subtle depth, clean separators, semantic icons, readable labels.

Color direction:
Midnight navy, pearl white, soft cyan for structure, jade for verified, violet for AI, gold for governance.

Avoid:
over-complex visuals, too many icons, vague layer names, low contrast, tiny labels, watermark.
```

## Project Mapping
- AndyAI Director
- PAIA-OS
- Knowledge Factory
- Human Attention
- Visual Artifact Stack

## Quality Gate
The viewer must understand the whole system as layers, not chaos.

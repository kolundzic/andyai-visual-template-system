# AVTS-009 — Tool Decision Matrix

## Category
Comparison Matrix

## Purpose
Compare tools, models, architectures, databases, or strategies in a clear objective visual.

## Best For
- vector database choices
- AI model comparison
- SaaS tool decisions
- architecture tradeoffs
- vendor evaluation
- build vs buy decisions

## Style Family
Pearl White Research

## Recommended Ratio
16:9

## Prompt

```text
Generate a professional tool decision matrix comparing [items].

Purpose:
Help the viewer choose the right option based on clear criteria.

Audience:
technical, business, strategic.

Compare these options:
[Option A]
[Option B]
[Option C]
[Option D]

Criteria:
- Best for
- Strength
- Weakness
- Complexity
- Cost / effort
- AndyAI recommendation
- Risk surface

Layout:
Clean matrix table with concise text, semantic icons, and a final recommendation strip.

Style:
AndyAI Pearl White Research, academic, clean, high-trust, readable, precise.

Color direction:
pearl white background, black text, jade recommended states, amber caution, cyan technical notes, gold final recommendation.

Avoid:
marketing hype, vague ratings, tiny text, fake logos, visual clutter, watermark.
```

## Project Mapping
- RAG Ingestion Factory
- Knowledge Factory
- AndyAI Automation
- Finance Engine
- Visual Canon

## Quality Gate
The matrix must make tradeoffs visible, not just rank winners.

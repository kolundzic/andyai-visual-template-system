# AVTS-006 — Mission Control Dashboard Mockup

## Category
UI / Dashboard Mockup

## Purpose
Create realistic app or SaaS dashboard mockups for control, monitoring, evidence, and guided action.

## Best For
- product demos
- pitch decks
- mission control UI
- admin dashboards
- SaaS previews
- mobile or desktop app concepts

## Style Family
Quantum Glass Interface

## Recommended Ratio
16:9 or 9:16

## Prompt

```text
Generate a realistic mission control dashboard UI mockup for [project name].

Purpose:
Show how a user controls, monitors, verifies, and approves the workflow.

Audience:
product users, partners, stakeholders, technical reviewers.

Screen:
[home dashboard / mission control / evidence board / approval queue / workflow board]

Include interface elements:
- top navigation with project name
- system status badge
- active workflow cards
- evidence log panel
- approval queue
- metrics cards
- timeline / activity stream
- final action button
- risk or warning area if relevant

Design language:
AndyAI Quantum Glass Interface, elegant dark mode, calm futuristic, premium SaaS dashboard, Japanese-inspired precision.

Typography:
Readable, well-spaced, professional sans-serif.

Layout:
Modular cards, realistic spacing, clear hierarchy, subtle glow, glass panels, status chips.

Color direction:
Midnight navy, transparent graphite cards, soft cyan data lines, violet AI accents, jade verified states, gold priority states.

Avoid:
cartoon UI, generic stock dashboard, tiny unreadable text, messy spacing, fake brand logos, watermark.
```

## Project Mapping
- AndyAI Director
- Finance Engine
- Agency OS
- TAPFORGE
- Visual Factory

## Quality Gate
The mockup must feel like a real product screen, not a decoration.

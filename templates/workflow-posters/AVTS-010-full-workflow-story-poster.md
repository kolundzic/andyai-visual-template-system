# AVTS-010 — Full Workflow Story Poster

## Category
Workflow Poster

## Purpose
Explain an entire workflow in one polished, memorable visual story.

## Best For
- end-to-end process explainers
- launch posters
- product demos
- educational diagrams
- visual story slides
- social/shareable canonical posts

## Style Family
Neon Ink Diagram

## Recommended Ratio
4:5 or 16:9

## Prompt

```text
Generate a full workflow story poster for [workflow / project].

Purpose:
Explain the complete process from input to verified output.

Audience:
beginners, business readers, technical readers.

Main story flow:
[Step 1] → [Step 2] → [Step 3] → [Step 4] → [Final Result]

Required sections:
- problem / input
- system action
- evidence / verification
- human approval
- final output
- reuse / memory

Exact labels:
[list labels exactly]

Hero visual:
[one central symbolic visual that represents the whole workflow]

Layout:
Strong title at top, central workflow path, supporting panels, bottom takeaway line.

Style:
AndyAI Neon Ink Diagram, premium academic sci-fi, controlled glow, elegant dark background, readable poster design.

Color direction:
ink black, pearl white, electric violet, soft cyan, jade green, warm gold.

Avoid:
chaotic cyberpunk, unreadable text, random decorative arrows, fake logos, watermark, copied public poster layouts.
```

## Quality Gate
The poster must make the workflow memorable and operationally understandable.

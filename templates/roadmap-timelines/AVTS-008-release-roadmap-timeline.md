# AVTS-008 — Release Roadmap Timeline

## Category
Roadmap / Timeline

## Purpose
Show project evolution, version releases, phases, milestones, and next steps.

## Best For
- repo releases
- public launch plans
- product roadmaps
- investor updates
- internal planning
- tutorial sequences

## Style Family
Dark Navy Operational

## Recommended Ratio
16:9

## Prompt

```text
Generate a release roadmap timeline for [project name].

Purpose:
Show project progress from current version to next milestones.

Audience:
project team, public users, partners, stakeholders.

Timeline items:
- v[version] — [milestone title]
- v[version] — [milestone title]
- v[version] — [milestone title]
- v[version] — [milestone title]

For each milestone show:
- version
- short title
- status
- proof / output
- next action

Layout:
horizontal or stepped timeline with clear version markers and status badges.

Style:
AndyAI Dark Navy Operational, professional, futuristic, readable, release-board style.

Color direction:
dark navy, cyan timeline lines, jade completed badges, amber in-progress, gold major milestones.

Avoid:
too much text, decorative timeline noise, fake dates, unclear status, watermark.
```

## Project Mapping
- all AndyAI repos
- TAPFORGE
- Director
- RAG Factory
- Visual Template System

## Quality Gate
The viewer must immediately see what is done, what is next, and what matters.

# 🅰️ AndyAI Visual Template System

**Version:** v0.1  
**Status:** Repo Scaffold  
**Parent Ecosystem:** AndyAI / AndyAI Visual Canon / AndyAI Visual Factory / AndyAI Visual Artifact Stack

AndyAI Visual Template System is the canonical library of reusable academic sci-fi visual templates, prompt systems, style rules, block diagrams, UI mockups, evidence cards, multilingual posters, and project-linked visual assets for the AndyAI ecosystem.

## Core Formula

Template ID → Project Context → Visual Prompt → Generated Draft → Human Review → Final Artifact → Reuse

## Purpose

This repository stores original AndyAI visual templates that can be called by ID and reused across projects.

Example:

```text
Use AVTS-004 for AndyAI Director.
Style: Japanese Future Academic.
Format: 16:9.
Language: English + Serbian.
```

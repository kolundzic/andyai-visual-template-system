# AndyAI Visual Quality Checklist v0.1

A template is acceptable only if it passes these checks.

## 1. Clarity Check
Can a beginner understand the main idea?

## 2. Structure Check
Is the visual flow obvious?

## 3. Text Check
Is the text readable and accurate?

## 4. Style Check
Does it fit the AndyAI visual identity?

## 5. Project Check
Can it be reused in at least one real AndyAI project?

## 6. Evidence Check
If the visual explains a process, does it show validation, proof, memory, or approval where needed?

## 7. Originality Check
Is the final template an original AndyAI structure, not a copied public layout?

## 8. Reuse Check
Can it be called later by ID and adapted quickly?

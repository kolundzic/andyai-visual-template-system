# AndyAI Master Visual Prompt Formula v0.1

Use this structure for every serious AndyAI visual prompt.

```text
Generate a [visual type] for [project / concept].

Purpose:
[what the visual must explain]

Audience:
[beginner / technical / business / academic / investor]

Core logic:
[main idea or system relationship]

Required elements:
[list of blocks, objects, roles, modules]

Exact labels:
[list exact text labels]

Evidence / governance layer:
[logs / approval / validation / memory / proof / status]

Style:
AndyAI academic sci-fi, elegant, precise, Japanese-inspired, calm futuristic, premium technical documentation style.

Color direction:
[dark navy / pearl white / jade / cyan / violet / gold]

Layout:
[card / flow / layered / matrix / dashboard / poster]

Format:
[16:9 / 4:5 / 1:1 / A4 / 9:16]

Avoid:
clutter, tiny text, fake logos, random labels, decorative arrows, unreadable typography, chaotic neon, generic stock look, watermark.
```

## Key Rule

Structure before beauty.  
Exact labels before decoration.  
Purpose before style.
